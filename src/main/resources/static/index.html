Специальные операции

1. Удалить одного персонажа по оружию
2. Минимальное время ожидания

Найти одного персонажа с наименьшим заполненным временем ожидания.

3. Поиск по саундтреку
4. Сделать героев печальными

Установить SORROW всем персонажам, у которых «Настоящий герой» = «Да».

5. Выдать автомобили

Посадить настоящих героев без автомобиля в красные Lada Kalina.

ID и дата создания назначаются автоматически. * — обязательное поле.

Саундтрек может быть пустой строкой. Время ожидания можно не указывать.
